# Margaux Bank — Free-hosting version

This is a static recreation of the Margaux Bank Airo website.

Files:
- index.html — page structure/content
- style.css — layout, typography, colors and responsive design
- script.js — mobile navigation and demo application form

## Publish for free with GitHub Pages

1. Create/sign in to GitHub.
2. Create a new **public** repository, e.g. `margaux-bank`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Under "Build and deployment", choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will give you a free URL ending in `github.io`.

The email form in this demo is front-end only; it does not actually send applications anywhere. Connect it to a form service later if your class project needs submissions.
